Data: 2026-11-03
Repozytorium: dashboard (AI-Agents)

Poniższe zadania zostały wyselekcjonowane specjalnie pod model 4B: są wąsko zdefiniowane, dotyczą 1 pliku, posiadają deterministyczne testy i nie wymagają skomplikowanych abstrakcji.

### ZADANIE 1: Testy jednostkowe dla `src/backend/utils/network.js`
**Cel:** Stworzenie kompletnego pliku testowego `src/backend/utils/network.test.js` w Vitest.
**Plik źródłowy:** `src/backend/utils/network.js` (24 linie)

**Prompt do wklejenia w Claude Code:**
```text
Stwórz plik testowy src/backend/utils/network.test.js w Vitest dla src/backend/utils/network.js.
Przetestuj funkcje:
1. getLocalLanIp():
   - Zamockuj moduł 'os' metodą vi.mock('os', ...).
   - Przetestuj przypadek, gdy os.networkInterfaces() zwraca interfejs IPv4 z internal: false (powinien zwrócić jego adres IP).
   - Przetestuj przypadek, gdy brak interfejsów zewnętrznych (powinien zwrócić fallback '127.0.0.1').
2. resolveDashboardUrl(req):
   - Gdy req posiada nagłówek x-forwarded-proto i x-forwarded-host (np. https i mydomain.com).
   - Gdy host to 'localhost:5173' lub '127.0.0.1' - powinien zwrócić URL oparty na getLocalLanIp() i process.env.PORT || 3001.
   - Gdy req jest null/undefined - powinien zwrócić domyślny fallback z LAN IP.

Na koniec uruchom: npx vitest run src/backend/utils/network.test.js i upewnij się, że wszystkie testy przechodzą.
```

```text
Funkcja sshCmd(s, remoteCmd) generuje polecenie SSH.
```

```text
W pliku src/index.css upewnij się, że znajdują się OBA poniższe bloki styli:
1. Styl dla focus-visible:
:focus-visible {
  outline: 2px solid var(--primary);
  outline-offset: 2px;
  border-radius: 4px;
}
2. Styl dla kursorów:
a, button, input, select, textarea, .cursor-pointer {
  cursor: pointer;

Uruchom: npm run lint oraz npx vitest run src/__tests__/a11y.test.tsx i upewnij się, że nie ma błędów lintera ani testów a11y.
```
